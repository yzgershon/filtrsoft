## 4. Technical foundation — what's actually possible

### 4a. Facebook Marketplace access
- **There is no public API and there never has been.** Marketplace is deliberately excluded from Graph API. Meta's model depends on keeping people inside the app.
- **Meta v. Bright Data (2024): Meta LOST and dropped the case.** Judge Chen ruled Meta's ToS **only binds logged-in users**, and does **not** prohibit scraping publicly available data while **logged out**.
- **Critical inversion:** this means a browser extension running in the user's **logged-in** session is on *worse* ToS footing than logged-out collection. Different enforcement risk (Meta sues companies, not individual browsers), but know which side you're on.
- **Practical hostility is the real cost, not the legal risk.** Facebook randomizes CSS class names, changes the DOM constantly, runs behavioral anti-bot detection, and aggressively rate-limits. Every DOM-based tool in this space breaks repeatedly. **This is a permanent maintenance tax, not a one-time build cost.**
- Logged-out Marketplace viewing is partially possible in the US but unreliable and limited.
- **Never ask users for Facebook credentials or session tokens.** Security disaster, gets their accounts banned. Flipify explicitly advertises that it never stores passwords, which tells you the market is sensitive to this.

### 4b. eBay sold comps — this got harder and it costs money
- **`findCompletedItems` (Finding API) was EOL'd February 2025.** The free path is gone.
- **Marketplace Insights API is Limited Release and closed to new applicants.** eBay grants it to major partners only. Do not plan around getting it.
- **Browse API is free** at 5,000 requests/day, but it only covers **active** listings, not sold. Asking prices run **20–50% above** what things actually clear at, so active listings are actively misleading.
- Realistic paths to sold data: **SoldComps** (from $9/mo, 1 request = up to 200 sold listings, 90-day window), Apify actors, Bright Data, or scraping it yourself.
- **eBay only exposes ~90 days of completed sales.** Everyone is bound by this window. Longer history is a moat you build yourself by storing what you pull, starting day one.

### 4c. Vision AI unit economics
- Rough image cost: a 2000×2000 image ≈ 5,300 input tokens.
- Per listing (4 photos + text ≈ 6,000 input, 500 output):
  - **Haiku 4.5** ($1/$5 per M): ≈ **$0.0085/listing**
  - **Sonnet 5** ($2/$10 per M): ≈ **$0.017/listing**
- At 500 listings/user/month: **$4.25 (Haiku)** vs **$8.50 (Sonnet)**.
- **This constrains your pricing floor.** A $12.99/mo plan with heavy Sonnet usage has almost no margin.
- **Correct architecture:** Haiku for cheap triage on every listing, escalate to Sonnet only for the deep on-demand analysis. Downscale images before sending. Cache aggressively (90% savings on repeated context). Batch API gives 50% off non-urgent work.

### 4d. Chrome extension platform
- **Manifest V2 is fully dead August 31, 2026.** That is nine days from this report. **Build MV3 only.**
- MV3 **prohibits remotely hosted code** — full functionality must be discernible from submitted source. Your logic lives server-side behind an API, not shipped as remote JS.
- Privacy policy is **mandatory** if you touch any user data. Missing/vague policy is a top rejection reason.
- Affiliate links require **explicit user action and disclosure** per Chrome Web Store policy.
- Permissions must be justified. Don't over-request.

### 4e. Mobile is a different product, not a port
- **iOS cannot run Chrome extensions. Period.** Apple's WebKit rule applies to every browser on iOS. Safari extensions exist but need Apple approval and are limited in scope.
- Android: Firefox, Kiwi, and Quetta support extensions. Chrome for Android does not.
- **Consequence:** your "phone app with a great UI" cannot be an overlay on the Facebook app. Options:
  1. Standalone alert-feed app (what Swoopa/Flipify do) — but that requires you to run the scraping infrastructure, which is the expensive, legally exposed, high-maintenance path.
  2. **iOS Share Sheet extension** — user hits Share on a listing inside the FB app, sends it to your app, gets the analysis back. **Legitimate, user-initiated, no scraping, and almost nobody does this.** Strongly recommended.

### 4f. Other retail APIs (for the new-vs-used arbitrage you mentioned)
- **Amazon PA-API is being deprecated May 15, 2026** in favor of Creators API. Also gated: needs 3 qualified sales to get in, 10 sales/30 days to keep. Real friction.
- **Best Buy Developer API** is live and open.
- **Walmart Affiliate/Content Provider API** requires approval as a content provider.
- **Keepa** (Amazon price history, 6B+ products) starts at **€49/mo**, no free tier, token-bucket rate limiting.
- **PCPartPicker has no public API.** Unofficial scrapers exist on GitHub and Apify.

## 5. The actual gap — what nobody does

Everything above is commodity. Here is what is genuinely unserved:

### 5a. Bundle decomposition (the big one)
Every existing tool values **one item against one comp**. That works for a bike or a couch. **It completely fails on a gaming PC**, because a "$400 gaming PC" listing is a *bundle of 7 components*, and its value is somewhere between $150 and $1,400 depending entirely on which GPU is inside.

There is no single sold comp for a custom PC. You have to:
1. Identify each component (often only visible in a blurry photo through a glass side panel)
2. Value each one against its own sold comps
3. Sum, then discount 10–25% for whole-unit sale dynamics
4. Compare against part-out value (**parting out yields 60–80% of new; selling whole yields 50–70%** — the spread IS the flip)

pcprice.watch does the math but **from specs the user types in**. howmuchisitworth.app does photos but **whole-unit, not component-level**. **Nobody does photo → component identification → per-part comps → part-out vs whole-unit recommendation, live on the listing.**

That is a real technical moat, it is exactly what you know from flipping PCs, and it is defensible because it requires domain knowledge that generic tools have no reason to build.

### 5b. Scam and red-flag detection tuned to tech
Directional figures from industry reporting (treat as approximate, sourced from SEO-heavy content):
- ~34% of Marketplace listings may be scam posts
- ~79% of users report encountering fraud
- $390M lost to online shopping scams in 2026, social marketplace fraud +54% YoY

**A "too good to be true" price is the primary scam signal, which means your deal-finder is structurally also a scam-finder.** Every tool that surfaces underpriced items is surfacing scams and calling them wins. The one that says *"this is 60% under market AND here are five reasons it's fake"* is more valuable than the one that just says HOT FLIP.

Tech-specific red flags nobody encodes: stock photos instead of real ones, no photo of the actual GPU, refusal to show it powered on and in BIOS, mining-farm indicators, "no returns cash only," account age, listing recency, price too round, location mismatch.

### 5c. Questions to ask the seller
**I found zero tools doing this.** It is the highest-value, lowest-cost feature on the list. For a PC: what's the exact GPU model and brand, was it used for mining, does it POST, do you have the original box, why are you selling, can you send a photo of it running with HWiNFO open. This is pure domain knowledge as a product feature and it is exactly what you learned the hard way.

### 5d. Buyer mode vs. flipper mode
You called this out yourself and it is genuinely absent from the market. Every tool assumes you're reselling. But the person who's been hunting a specific graphics card for two months has a completely different question: not "what's my margin" but **"is this a fair price and should I act now or wait?"** That needs price *trend* data, not just profit math. Different product, same engine, and it roughly doubles your addressable audience.

### 5e. Decision economics nobody computes
- **Drive-time math.** $80 profit on a 50-minute round trip is a bad job. Nobody computes effective hourly rate.
- **Local market variance.** A GPU clears at different prices in Boston vs rural Ohio. All these tools use national comps.
- **Sell-through rate.** "Worth $600" is meaningless if it takes 90 days to move. SuperFlip is the only one advertising this.

## 6. Monetization

**Subscription is the model. Affiliate is not.**

- eBay Partner Network pays **1–5%** with a **24-hour cookie**, and **electronics is the worst category at 1–2%**. Your exact vertical is the worst-paying one. Affiliate is a rounding error here.
- Amazon Associates requires sales thresholds to even keep API access.
- Recommended: **freemium with a hard scan cap.** Free tier ~10 full analyses/month (matches Flipalyze, undercuts flippr's 7). Paid at **$14.99–19.99/mo**, positioned above flippr's $12.99 on depth, radically below Swoopa's $47.
- Later adjacencies: part-out planner, listing generator, inventory + 1099-K bookkeeping (real pain for anyone flipping at volume).

## 8. Recommended product

**Name TBD. One sentence: the tool that tells you what's actually inside a used PC listing and whether it's worth your drive.**

**Wedge: PC, GPU, and computer hardware listings only.** Not furniture, not clothes, not cars. The one category where your knowledge is real, where valuation is genuinely hard, where generic tools structurally fail, and where the buyers are online and reachable.

**V1 scope (6–8 weekends):**
1. MV3 Chrome extension, overlays Facebook Marketplace listing pages
2. Photo analysis → identify components (GPU model + variant, CPU, RAM, storage, PSU)
3. Per-component sold comps → **part-out value vs. whole-unit value, side by side**
4. Verdict with the number that matters: profit, and profit per hour including drive time
5. **Red flag panel** — scam and condition risk with specific reasons
6. **"Ask the seller this"** — generated, copy-pasteable, model-specific
7. Two modes: **Flip** (margin) and **Buy** (fair price + wait-or-act)

**Explicitly out of scope for V1:** other categories, mobile, alerts/monitoring, auto-messaging, cross-listing. Alerts are the commodity everyone fights over. Don't enter there.

**Distribution:** this is the part that makes it work. PC building and flipping content performs enormously well on YouTube, TikTok, and Instagram, and you have genuine receipts from flipping PCs sourced off Marketplace. Post the sourcing runs and the profit breakdowns with the tool naturally in frame. **Your product and your content goal point the same direction, which was not true of any other idea considered.**

## 9. "Am I missing anything?" — the answer

1. **The category is crowded.** Nine+ shipping competitors. You did not know this. Now you do.
2. **flippr already does your overlay idea** at $12.99/mo. Study it before you build.
3. **Underpriced AI already values items from photos.** Your photo idea is not novel on its own. Component-level decomposition is.
4. **Scam detection may be worth more than deal detection.** Underpriced = scam is the default case, not the exception.
5. **Sell-through matters more than value.** "Worth $600" is worthless if it sits 90 days.
6. **Local price variance** — everyone uses national comps. You're in Boston.
7. **Drive-time economics** — nobody computes profit per hour.
8. **Negotiation scripting** — what to offer and the exact message. Zero tools do this.
9. **Safety** — you drove alone to strangers' houses as a minor. Meet-in-public guidance is cheap, genuinely useful, and extremely content-friendly.
10. **The seller side is a bigger audience than the buyer side.** Everyone sells eventually. "What should I list this at" has more users than "is this a deal."
11. **iOS kills the extension plan on mobile.** Share Sheet is the answer.
12. **MV2 dies in 9 days.** MV3 only.
13. **Sold comps now cost money.** Budget for it. Store everything you pull.
14. **eBay electronics affiliate is 1–2%.** Affiliate is not a revenue plan.
15. **Never touch Facebook credentials.**
16. **1099-K bookkeeping** is a real, growing pain for volume flippers. Natural expansion.
