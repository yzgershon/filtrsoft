The promotion

Uses the View Transitions API where the browser has it, and a FLIP fallback everywhere else — measure first, invert, play. Both paths animate transform and opacity only, so nothing reflows mid-motion.

Enter is 420ms, exits are 150ms. An exit that lingers as long as its entrance is what makes an interface feel slow.

Why the filters changed

The old chips were identical pills with no grouping, no state beyond colour, and no keyboard model. This is a segmented control — a real radiogroup where arrow keys move between options and aria-checked announces the active one.

The indicator slides, so the active option is signalled by position as well as colour. Colour alone is never the only cue.

Secondary filters are toggle buttons with aria-pressed and a checkmark that appears when on — again, not colour alone. Every target clears 44px.

The 28-day rule

Anything older is gone from the feed entirely. On the current data that drops 8 of 200, five of them FAIR calls on listings 46 to 137 days old — either sold or never good. Showing them was the app quietly wasting your attention.

Accessibility, not decoration

Focus rings are visible and never removed. Every icon-only button has an aria-label. The nav marks its location with aria-current. Press states use scale, not layout shifts. Everything honours prefers-reduced-motion.
